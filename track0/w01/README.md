# W01 — What is a Qubit?

**Track:** 0 — Foundations  
**Prerequisites:** None  
**Duration:** ~60 minutes

---

## Overview

This workshop introduces the qubit — the fundamental unit of quantum information. We build intuition for superposition and measurement from scratch, using both mathematical notation and visual tools, without assuming prior quantum mechanics knowledge.

By the end of this session you will be able to:
- Describe what a qubit is and how it differs from a classical bit
- Represent a qubit state using Dirac notation and as a vector
- Visualise qubit states on the Bloch sphere
- Explain what measurement does and why it is irreversible
- Write and run a basic single-qubit circuit in Qiskit

---

## Topics Covered

- Classical bits vs qubits
- Dirac (bra-ket) notation
- Superposition — what it means and what it doesn't mean
- State vectors and the unit sphere constraint
- The Bloch sphere
- Measurement, probability, and the Born rule
- Running a single-qubit circuit on a simulator
